# Project Overview: Advanced Data Analysis and Visualization with the Olist E-Commerce Dataset

This project demonstrates a comprehensive approach to data analysis and visualization using the widely recognized Brazilian E-Commerce Public Dataset by Olist. The project is structured into two main components:

1. SQL_Brazil (Data Preparation and Analysis in SQL)

- This module includes SQL scripts focused on data preprocessing, transformation, and schema design.

- The scripts prepare the raw dataset for advanced querying by structuring the data and optimizing it for insight generation.

### Key tasks include:

- Data cleaning and normalization

- Creation of relational database schema

- Writing complex queries to extract meaningful insights

2. Power BI Dashboard Report (Visualization & Insights)

- This component includes a Power BI dashboard presented in a PDF report format.

- It visualizes key performance indicators (KPIs), trends, and insights derived from the dataset.

- The dashboard covers various analytical aspects such as:

- Seller performance

- Delivery time analysis

- Customer behavior

- Product category trends

### Note:

While both components utilize the same underlying dataset, they were developed independently to highlight different aspects of data analysis:

- The SQL_Olist module emphasizes data engineering and querying capabilities.

- The Power BI Dashboard focuses on interactive reporting and business intelligence visualization.






# 📁 Project Overview
This project focuses on comprehensive business analysis and data visualization of a Brazilian e-commerce marketplace using the public Olist dataset. The goal is to derive actionable insights related to sales, customer behavior, seller performance, and delivery logistics by building interactive dashboards in Power BI and transforming data using Power Query. 


🎯 Objectives
Analyze overall business performance through KPIs like total revenue, total orders, and average order value.

Identify top-performing sellers, cities, and product categories.

Understand delivery performance and its impact on customer satisfaction.

Analyze customer review patterns and behavior.

Suggest business improvements through data-backed recommendations.

🧩 Dataset Description
📌 Source: Kaggle – Brazilian E-Commerce Public Dataset by Olist

📦 Records: 100,000+ orders from Oct 2016 to Sep 2018

📊 Tables Used:

orders, order_items, order_reviews, products, sellers

order_payments, customers, geolocation

🛠️ Tools & Technologies
Tool	Purpose

💡 Key Insights
São Paulo contributes ~41% of total orders.

73%+ of customers use credit cards as payment method.

Customers who received late delivery mostly left 1–2 star reviews.

Highest orders are from bed_bath_table and health_beauty categories.

Average delivery time decreased from 55 to 8 days over 2 years.

Only 10% of customers are repeat buyers – indicating potential churn.

Some orders were delayed by over 200 days, seriously impacting reviews.

✅ Recommendations
📉 Reduce Late Deliveries: Use regional warehouses and adjust estimated dates realistically.

📝 Investigate Low Reviews: Analyze 1-star ratings through customer feedback surveys.

🎯 Cross-Selling Strategies: Suggest relevant products to increase average order size.

📦 Freight Optimization: Re-evaluate cities with high logistics cost and low order value.

🛍️ Reward Loyal Customers: Launch loyalty programs for repeat buyers.

🔎 Seller Monitoring: Track monthly seller performance to reward consistency and penalize delays.

📆 Analyze Seasonality by Category: Use category-level patterns for targeted marketing.
